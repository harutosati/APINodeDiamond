# APINodeDiamond

APINodeDiamond is a distributed, async data processing engine that leverages load-balancing and auto-scaling for high-performance Node applications.

With APINodeDiamond, you get a lightweight tool that stays out of your way.

**What you get**

- APINodeDiamond is a distributed, async
- data processing engine that leverages
- load-balancing and auto-scaling for high-performance

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/APINodeDiamond.git`
2. `cd APINodeDiamond`
3. Install in editable mode: `pip install -e .`

## Configuration

APINodeDiamond is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
